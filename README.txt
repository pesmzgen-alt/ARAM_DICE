ARAM DICE website
=================

Files:
- index.html
- assets/sign-colors.jpeg
- assets/color-dice-reference.jpeg (your first uploaded design reference)

Run locally:
Open index.html in a browser.

Publish with GitHub + Netlify:
1. Create a new GitHub repository named aram-dice.
2. Upload index.html and the entire assets folder (keep the folder structure).
3. Open https://app.netlify.com/ and sign in.
4. Choose Add new project / Import an existing project.
5. Connect GitHub and select the aram-dice repository.
6. Build command: leave empty. Publish directory: leave as the repository root (or enter . if required).
7. Click Deploy. Netlify will give you a public website link.

To update the website later:
Edit index.html or replace an image in assets, then commit/push to GitHub. Netlify will redeploy automatically.
